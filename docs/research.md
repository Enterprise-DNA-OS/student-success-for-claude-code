Education Cloud Core's listed nonprofit rate is US$87 per user/month billed annually. A 25-paid-seat scenario is US$26,100 per year. This is arithmetic, not evidence of an actual NZ or AU customer's invoice. [Pricing](https://www.salesforce.com/education/pricing/). Eligible nonprofit status, granted seats, discounts and contracts matter. No exact EDNA customer use or invoice was found in available repository customer/CRM context. Live CRM was not queried. The buyer score reflects this uncertainty.

[Envoy pricing](https://envoy.com/pricing/) lists Premium at $362 per location/month billed annually. Three locations model 13,032 currency units annually before platform fees, but the currency and a real buyer invoice were not verified. The kiosk and visitor experience make it less suitable for a staff-only database. [Salesforce Order Management](https://www.salesforce.com/commerce/order-management/pricing/) requires a quote, so the annual-bill score is low rather than an invented estimate. Order orchestration also adds integration scope.

Searches for Education Cloud alternatives returned G2, Gartner and comparison articles. This supports a modest search score, not a measured volume or ranking promise. [G2 alternatives](https://www.g2.com/products/agentforce-education-formerly-salesforce-education-cloud/competitors/alternatives). No unverified competitor limitations appear in the page.

[Salesforce's Australian Student Success page](https://www.salesforce.com/au/education/student-success-software/) describes support plans, watchlists, summaries and service programmes. This supports the chosen rituals and regional availability, not a claim that EDNA customers use it. [Developer data model](https://developer.salesforce.com/docs/platform/data-models/guide/student-success.html) and [report export instructions](https://trailhead.salesforce.com/content/learn/projects/create-reports-and-dashboards-for-sales-and-marketing-managers/manage-reported-data) support the import plan.

The reference build read before authoring was utility-accounts-for-claude-code, including README, CLAUDE and smoke tests. The new project was scaffolded from the single Command Centre template. A preserved-path workspace alias places it beside Command-Center inside this sandbox's writable workspace. No Command-Center Git operation was used.

The Supabase changelog and RLS documentation were checked. The September database changes concern extensions and custom operators this schema does not use. This build has no dependency on a live Supabase project.
