# Write the Monday adviser review

Read current records before answering. Use --json when assembling a report. Quote the source IDs. Never invent a date, outcome, consent or interaction. Use caseload, attention and referral-chase from the combined output. Group by adviser, identify missing owners and overdue work, and draft next steps without claiming anyone was contacted.
