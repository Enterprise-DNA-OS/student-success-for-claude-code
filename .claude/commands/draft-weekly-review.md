# Draft the weekly adviser fact pack

Read current records before answering. Use --json when assembling a report. Quote the source IDs. Never invent a date, outcome, consent or interaction. The command writes a private JSON fact pack under drafts/. Read it and write an editable Markdown draft beside it, referencing the recorded facts. Leave unverified statements out. Never send or share it.

```bash
npm run students -- draft-weekly-review
```
