# Record a plan review and next review date

Read current records before answering. Use --json when assembling a report. Quote the source IDs. Never invent a date, outcome, consent or interaction. Act only on the operator's verified instruction. If names match several records, list candidates and obtain the exact ID. Do not treat a plan as complete while its actions are open.

```bash
npm run students -- review-plan <id> --next=YYYY-MM-DD --outcome="<review evidence>" --actor="<operator>"
```
