# Add a view

Turn the operator's question into a read-only query using verified fields. Use caller permissions on any new database view. Put the query in views.json, use brand.json, and render with npm run view. Check the resulting HTML and totals against the source records. Add a representative query assertion to npm test. Never add a form, button that changes data, public link or automatic send.
